MOȘ CRĂCIUN SUNĂ — iPhone-first web app

This starter is a web app, not a native iOS app. It has a welcome screen, Santa video call, timed response pauses, and a goodbye screen.

REQUIRED VIDEO FILES (not included):
mos-1.mp4 — "Ho, ho, ho! Bună! Sunt Moș Crăciun și te sun de la Polul Nord! Ai fost cuminte anul acesta?" (6-second pause after clip)
mos-2.mp4 — "Ce minunat! Și spune-mi, vrei să-mi cânți un colind? Te ascult cu mare drag!" (20-second pause after clip)
mos-3.mp4 — "Bravo! Ce frumos ai cântat! Îți mulțumesc! Ce cadou ți-ai dori de Crăciun?" (currently no pause; add one if desired)
mos-4.mp4 — "Ho, ho, ho! Îți doresc un Crăciun magic! Te îmbrățișez! La revedere!"

Make four MP4 videos with an original/licensed Santa performance and voice. Use H.264 video and AAC audio for iPhone compatibility. Put them alongside index.html, preserving names.

PHONE-ONLY DEPLOYMENT:
1. Use a mobile-friendly static hosting service supporting file uploads (for example, GitHub via its mobile browser interface and GitHub Pages).
2. Upload index.html, manifest.webmanifest, and the four video files to the same published folder.
3. Open the HTTPS site in Safari on iPhone.
4. Use Share > Add to Home Screen.

The app does not request microphone/camera access and does not record the child. It plays prerecorded clips. An internet connection is required for the hosted videos; offline playback is not implemented.

Before publishing to the App Store, use a native wrapper or iOS implementation with adequate native functionality and comply with Apple App Review requirements, privacy disclosures, licensing and parental protections.
